### 常见问题

**需要账号吗？** 不需要。CCView 不登录、不收集 API Key，认证完全继承本机已登录的 Claude Code CLI。

**数据存在哪里？** 产品数据只在本机（127.0.0.1）；这个主页的访客统计与内测申请，存在我自己的云端数据库里。

**和终端里的 claude 命令什么关系？** 同一个 CLI，不同入口。CCView 只把过程变成可见、可点的界面。
